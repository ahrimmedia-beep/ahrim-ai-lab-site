# AI voice website

Company website with a built-in AI voice assistant. A visitor presses a button and talks to the assistant in the browser. The assistant answers questions about the services and books a callback.

## What it does

- Voice conversation in the browser, with no app and no phone call.
- A callback request goes to an automation that calls the client back with an AI phone agent.
- Leads arrive in Telegram and Google Sheets.

## Stack

Next.js, React, TypeScript, Tailwind, OpenAI Realtime API (WebRTC), n8n, Voximplant, Docker.
